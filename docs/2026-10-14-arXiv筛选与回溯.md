# arXiv 筛选修正与近期回溯

## 问题与修改顺序

2026-10-10 与 2026-10-12 正式运行分别抓到 49、25 篇 arXiv，却均选出 0 篇。
先修正规则，再以保存的真实 10 月 12 日 RSS 重放：合格候选从 0 增至 1，恢复了
`2610.13859`（扩散激活外延）。其他 24 篇仍有 3 篇被关键词/无关 MD 排除、21 篇被主题排除。
恢复的方法识别没有填满 5 篇，因此再增加缺额回溯。

## 规则修正

- 补充外延、外延生长、分子束外延及具体外延方法。
- ALD、CVD、PLD、PVD、MBE 缩写需有薄膜、基底、沉积、生长等语境；不接受裸缩写。
- 摘要中的明确薄膜制备方法与实验/合成证据可以建立主题，不再必须出现字面 `thin film`。
- 配置中的 neural network、large language model、quantum computing、astrophysics、cosmology
  改为条件排除：标题须有具体相关研究主题，或摘要须有明确制备方法及实验依据。
  自定义的其他排除词仍执行硬排除；不会清空仓库变量。
- 无关 MD 仍排除。仅当 MD 不在标题、摘要明确归属于先前研究、本文有实验制备依据，且
  MD 所在句没有“本文采用”表达时，视为背景提及。此规则是保守文本启发式，不代替全文审查。
- 聚变、空间等离子体、无实验室语境的通用模拟继续排除。
- 真实回溯审查发现一篇 3D 打印软圆柱的宏观起皱研究，把外层称为 film。
  增加增材制造缺少明确薄膜沉积方法时的排除，避免用它填充薄膜配额。

## 回溯与优先级

1. 每日 RSS 走去重、近 90 天推送历史、关键词、研究主题门槛。
2. 当合格 arXiv 少于其配额时，按溅射/空心阴极、薄膜、实验室等离子体三类主题查询近 7 天。
3. 如仍不足，再查询 7–14 天。七天边界允许重叠，以版本无关 ID、DOI、规范化标题去重。
4. 先选择当天合格 arXiv，再从 7 天、14 天池中补足缺额；每个池内维持相关性排序及主题软平衡。
5. 回溯使用初次提交日期，不把较早论文的新版本当作近期新文献。
6. 不受原先三个 RSS 分类限制，但每个候选仍经过同一主题门槛。
7. arXiv 与 Semantic Scholar 的 5+5 配额独立；Semantic 经典补选保留原有排名政策。

接口查询采用 arXiv API 文档规定的 `submittedDate` UTC 分钟区间、布尔查询、分页及至少
3 秒请求间隔。每页最多 100 篇，每主题每窗口默认最多扫描 200 篇；有截断或错误会记录。
请求超时 30 秒，429/暂时性服务错误最多尝试 3 次，失败不丢弃其他主题/来源的候选。

官方说明：https://info.arxiv.org/help/api/user-manual.html

## 配置

| 变量 | 默认 | 含义 |
|---|---|---|
| `ENABLE_ARXIV_BACKFILL` | `true` | 是否启用缺额回溯 |
| `ARXIV_BACKFILL_MAX_DAYS` | `14` | 仅允许 7 或 14 |
| `ARXIV_BACKFILL_RESULTS_PER_TOPIC` | `200` | 每主题每窗口最大候选数 |

## 可核查输出

`logs/eligibility_report.json` 保存各批次、各来源逐级数量，文献标识、淘汰步骤与原因、
回溯错误及最终选择。经典 Semantic 候选也走相同的门槛审计。
工作流无论正式运行还是 dry run 都上传 `literature-diagnostics` artifact。
`logs/dry_run_selection.json` 新增回溯窗口和提交日期；邮件中补选 arXiv 有回溯标记及日期。
dry run 不发送邮件、不改变推送历史或每日送达账本。
